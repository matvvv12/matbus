MatBus в Telegram (Mini App) — как это работает
================================================
Бот просто открывает вашу веб-версию приложения (ту же, что вы смотрите в Chrome) прямо в Telegram.
Поэтому любые мои обновления попадают в бот после копирования файлов — как и раньше.

ЕДИНОРАЗОВАЯ НАСТРОЙКА
1) В Telegram откройте @BotFather -> /newbot -> придумайте имя и логин -> скопируйте токен.
2) Скопируйте bot\config.example.json в bot\config.json и вставьте токен вместо текста-заглушки.
   (Токен никому не показывайте.)

РЕЖИМ А — «БЫСТРЫЙ» (правки видны сразу, ПК должен быть включён)
Подходит для тестирования. Нужно 3 окна терминала (cmd) в папке matbus:
 0. Один раз установить туннель:  winget install --id Cloudflare.cloudflared   (потом перезапустить cmd)
 1. Окно 1:  start-app.bat          — приложение (то же, что npx expo start --web --clear)
 2. Окно 2:  tunnel.bat             — покажет адрес вида  https://что-то.trycloudflare.com  (скопируйте его)
 3. Окно 3:  bot.bat                — бот запущен
 4. В Telegram боту: /start, затем  /url https://что-то.trycloudflare.com
 5. Нажмите «Открыть MatBus» или кнопку «MatBus» в меню чата с ботом.
Дальше: я присылаю архив -> вы копируете файлы с заменой -> приложение в боте обновляется само
(закройте и откройте мини-приложение, если не обновилось).
Минусы: адрес туннеля меняется при каждом перезапуске tunnel.bat (тогда снова /url …);
первая загрузка в режиме разработки медленнее.

РЕЖИМ Б — «ПОСТОЯННЫЙ» (работает без включённого ПК)
Приложение один раз публикуется на бесплатном хостинге, адрес постоянный.
 1. Запустите deploy.bat (при первом запуске войдите в Netlify и создайте сайт — подсказки в окне).
    Альтернатива без командной строки: выполнить  npx expo export --platform web  и перетащить папку dist на https://app.netlify.com/drop
 2. Боту: /url https://ваш-сайт.netlify.app   (один раз)
 3. После каждого моего обновления: скопировать файлы -> запустить deploy.bat -> открыть приложение в боте заново.
Плюс: быстро грузится, можно пользоваться и показывать другим.

ВАЖНО
- Бот (bot.bat) нужен только чтобы задать/сменить адрес. Когда адрес задан, кнопка меню остаётся в Telegram и без него.
- Данные (избранное, места, тема) хранятся в браузере Telegram для этого адреса. При смене адреса (режим А) они сбросятся —
  в режиме Б адрес постоянный, поэтому данные сохраняются.
- Геолокация: Telegram спросит разрешение. Если отказали: Настройки Telegram -> Конфиденциальность -> Геопозиция.
- Файл vitebsk.json (ваши реальные данные) входит в сборку: если обновляли данные скриптом загрузки — перед deploy они уже на месте.
- Если адрес туннеля открыт в браузере — доступ к вашему приложению есть у любого, кто знает ссылку. Не публикуйте её.
