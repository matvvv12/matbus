MatBus — запуск Telegram Mini App
=================================

Что изменено
------------
Теперь после /start бот сразу показывает кнопку «Открыть MatBus». Пользователь не должен отправлять ссылку.
Если в bot/config.json задан фиксированный HTTPS-адрес, кнопка открывает его напрямую.
Если адрес не задан, бот использует Main Mini App по ссылке https://t.me/<username>?startapp.

Однократная настройка Main Mini App
-----------------------------------
1. Убедитесь, что веб-версия MatBus опубликована по постоянному HTTPS-адресу (например, после deploy.bat на Netlify).
2. Откройте @BotFather -> /mybots -> выберите своего бота.
3. Откройте Bot Settings -> Configure Mini App (или Main App) -> Enable/Configure.
4. Укажите постоянный HTTPS-адрес опубликованного MatBus и сохраните.
5. Перезапустите bot.bat. После этого /start отправляет кнопку открытия приложения без запроса ссылки у пользователя.

Как заменить файл
-----------------
Из корня проекта MatBus распакуйте архив с сохранением структуры и замените:
  bot/bot.mjs
  TELEGRAM.txt

Запустите bot.bat заново.

Для временного Cloudflare Tunnel владелец бота по-прежнему может задать новый адрес командой /url https://....trycloudflare.com.
Обычным пользователям отправлять ссылки боту не требуется.
