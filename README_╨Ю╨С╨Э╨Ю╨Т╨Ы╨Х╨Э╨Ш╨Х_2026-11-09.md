# MatBus — обновление интерфейса и расписаний (09.11.2026)

## Что изменено

- Переработана карточка остановки в существующем визуальном стиле MatBus: сохранены Manrope, цвета темы, стеклянные карточки и текущая система анимаций.
- В карточке остановки сверху всегда доступны ближайшие отправления по каждому виду транспорта, ниже — общий список ближайших рейсов. Оба списка учитывают обе стороны остановки: выбор стороны больше не скрывает троллейбусы или другие виды транспорта, которые могут подходить с противоположной платформы.
- Добавлены вкладки по видам транспорта и выбор конкретного номера маршрута с полным расписанием, выбором дня на 14 дней вперёд и разбивкой по направлениям.
- Переключатель стороны используется для выбора физической платформы на карте; списки ближайшего транспорта и полное расписание показывают все стороны, чтобы рейсы не пропадали из-за выбранной стороны.
- Нажатие на ближайший рейс открывает нужное направление маршрута на карте. В превью можно переключить направление, посмотреть последовательность остановок и вписать весь маршрут в экран.
- Для автобусов, троллейбусов и маршруток линия маршрута уточняется по уличной сети, если сервис маршрутизации доступен; иначе остаётся линия по координатам остановок. Для трамвая сохраняется прокладка по точкам остановок.
- В планировании поездки добавлены календарь на 14 дней и аналоговый 24-часовой циферблат: часы и минуты выбираются касанием или перетаскиванием по циферблату, стрелка поворачивается с анимацией.
- Добавлены отметки `≈` для расчётного времени маршруток.

## Проверка данных

Снимок данных в приложении: `2026-11-08T07:20:31.310Z`.

- 350 остановок.
- 113 маршрутов: 58 автобусов, 16 троллейбусных, 7 трамвайных и 32 маршрутных такси.
- 14 947 записей расписания.
- После сверки последовательностей маршрутов у каждой остановки в последовательности есть хотя бы одна запись расписания для этого маршрута.
- В исходной выгрузке 2 409 строк не содержали названия направления. Направление автоматически восстановлено только там, где сопоставление с последовательностью маршрута однозначно. Остались 2 неоднозначные записи — они явно обозначаются как «Направление не указано в источнике».
- 5 196 записей расписания помечены в данных как расчётные и в интерфейсе отмечаются знаком `≈`. Особенно внимательно проверяйте такие времена маршруток: это ориентир, а не подтверждённое официальное время прибытия на каждую промежуточную остановку.
- У 61 остановки нет координат в исходном каталоге. Эти остановки сохранены в поиске и расписании, но без достоверных координат их нельзя корректно поставить на карту. Координаты намеренно не выдумывались.
- «Старинки» остаётся в каталоге, хотя в текущем снимке у неё нет маршрута и записей расписания.

## Важные ограничения

- Приложение показывает ближайшие отправления по расписанию, а не реальное положение транспорта. Для отображения движущегося автобуса/троллейбуса нужен отдельный достоверный GPS/API-фид перевозчика; в имеющихся данных его нет.
- Маршрут на карте — это путь по последовательности остановок. Он не означает, что конкретный транспорт уже находится на этой линии.
- Остановки без координат остаются доступны в поиске и расписании, но не могут быть точно отображены на карте до получения координат из надёжного источника.
- Расписание маршруток с отметкой `≈` расчётное и требует отдельной проверки у перевозчика.

## Обновление существующего проекта

Распакуйте содержимое архива поверх текущей папки проекта с заменой файлов, затем в терминале из корня проекта выполните:

```bash
npm install
npx expo export --platform web
git add .
git commit -m "Обновление MatBus: остановки, расписания и карты маршрутов"
git push
```

Публикация на GitHub Pages сработает через уже настроенный в репозитории workflow.
