MatBus — расширенное расписание остановок и выбор времени маршрута

Установка:
1. Распакуйте архив в корень существующей папки MatBus.
2. Сохраните структуру папок и согласитесь на замену 4 файлов.
3. Не заменяйте src/data/vitebsk.json: в вашем проекте уже есть текущая база маршрутов и расписаний.
4. В PowerShell из корня проекта выполните:

   git add src/components/StopCard.tsx src/services/schedule.ts src/screens/RoutesScreen.tsx src/models/stop.ts
   git commit -m "Add full stop timetables and custom departure time"
   git push

После push GitHub Actions автоматически пересоберёт и опубликует GitHub Pages.

Что изменено:
- На карточке остановки появились вкладки по типам транспорта и полный список номеров маршрутов каждого типа.
- При выборе номера показывается полное расписание по направлениям на выбранную дату.
- Для остановки можно выбирать любой из ближайших 14 календарных дней; расписание сопоставляется с типом дня (будни/суббота/воскресенье).
- Время, рассчитанное по интервалу (например, для маршруток), отмечается знаком ≈.
- В планировщике маршрута можно выбрать дату на 14 дней вперёд и ввести произвольное время в формате ЧЧ:ММ.
- В найденных вариантах теперь дополнительно указывается дата отправления.

Примечание:
Расписание на будущие даты повторяет соответствующий тип дня из имеющихся данных. Специальные праздничные изменения и временные отмены рейсов автоматически не учитываются.
